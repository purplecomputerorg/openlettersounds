Open Letter Sounds

Free phonics sounds for US English: one clean clip for each letter sound, plus alternates.

They are CC0, so you can use them in anything, with no credit needed. Every clip is a short mono WAV, trimmed and set to the same loudness.

Press a letter key to hear its sound!

Download all sounds (.zip) How they are made, on GitHub
Each letter now also shows new takes that passed the automatic checks, best guess first. Tap one to hear it, tap ★ on any that would make a good alternate (as many as you like), then send your picks. They stay in this browser until you do.

Made by Purple Computer. The voice is synthetic (OpenAI gpt-audio-1.5, voice marin). Each clip's exact prompt is in sounds.json, inside the zip.
